StickyUp password reset setup
=============================

The reset flow sends a one-time link by email. Configure these environment
variables on the server before using it:

SMTP_HOST       SMTP server host name
SMTP_PORT       SMTP server port (defaults to 587)
SMTP_USERNAME   SMTP account/user name
SMTP_PASSWORD   SMTP password or provider app password
MAIL_FROM       Verified sender address
APP_BASE_URL    Public site origin, for example https://your-site.example

Keep SMTP_PASSWORD in the hosting provider's secret/environment-variable
settings. Do not commit mail credentials to GitHub. APP_BASE_URL should be the
public HTTPS origin without a trailing slash or application path.

Each reset link expires after 30 minutes and can be used once. Only a hash of
the reset token is stored in the database. The forgot-password response does
not reveal whether an email address has an account.

Without SMTP settings, the forgot-password page reports that email delivery
has not been configured. The application cannot deliver reset links until a
working SMTP account and sender address are supplied.
